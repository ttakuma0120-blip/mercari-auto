# メルカリ古着 商品紹介文自動生成ツール

写真をいくつか載せるだけで、**目を引くタイトル**・**購買意欲をそそる商品紹介文**など、メルカリ出品に必要な情報を自動で生成するPythonツールです。

> **別フォルダに「公開用」があります**（固定テンプレなし・全文を売れる文章として生成）。他者に配布する想定ならこちらを使ってください。  
> → `..\メルカリの商品紹介_公開版\`（`README.md` 参照・ポート **8502**）

## 生成される内容

| 項目 | 説明 |
|------|------|
| タイトル | 30文字以内の目を引くタイトル |
| 商品紹介文 | 200〜400文字の購買意欲をそそる説明文 |
| 推奨カテゴリ | メルカリのカテゴリ候補 |
| 状態の補足 | 写真から分かる状態情報 |
| 検索キーワード | 検索されそうなキーワード |

## セットアップ手順

### 1. リポジトリのクローン or フォルダに移動

```powershell
cd "c:\〇AIエンジニア\試み\メルカリの商品紹介"
```

### 2. 仮想環境の作成（推奨）

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. パッケージのインストール

```powershell
pip install -r requirements.txt
```

### 4. APIキーの設定

`.env.example` をコピーして `.env` を作成し、APIキーを記述します。

```powershell

```


**注意**: `.env` はGitにコミットしないでください（`.gitignore` に含まれています）。

## 使い方

### 方法1: Webフロントエンド（推奨）

画像をドラッグ＆ドロップでアップロードできるWebアプリです。

```cmd
install.bat      ← 初回のみ：パッケージインストール
start_app.bat    ← Webアプリを起動（黒いウィンドウが残る）
launch_quick.bat ← おすすめ：裏でStreamlit起動→ブラウザだけ開く（ワンクリック）
```

ブラウザが開き、http://localhost:8501 で操作できます。

### ワンクリックで使いたいとき（`launch_quick.bat`）

**ブラウザのアドレス欄に URL だけ打っても、Streamlit が動いていなければ表示できません**（どこかでサーバーを起動する必要があります）。

代わりに **`launch_quick.bat` をダブルクリック**（またはショートカットをデスクトップに置く）すると次のように動きます。

- **8501 が空いていれば** … ウィンドウを出さずに Streamlit を裏起動し、数秒後にブラウザで `http://localhost:8501/` を開く
- **すでに起動済みなら** … ブラウザを開くだけ（二重起動しにくい）

終了するときは **タスクマネージャー** で `streamlit` や `python` を終了するか、従来どおり `start_app.bat` のコンソールを閉じる方法を使ってください。

1. 写真をアップロード（複数枚可）
2. 「商品紹介文を生成」ボタンをクリック
3. タイトル・紹介文などをコピーしてメルカリに貼り付け

### 方法2: コマンドラインから実行

```powershell
run.bat images\item1.jpg images\item2.jpg
```

### 例

```powershell
# 1枚だけ
run.bat images\item_front.jpg

# 複数枚（表・裏・タグなど）
run.bat images\front.jpg images\back.jpg images\tag.jpg
```

## トラブルシューティング

### `404 NOT_FOUND` / 「gemini-2.0-flash は新規ユーザーには利用できなくなりました」

Google が **Gemini 2.0 Flash** を段階的に廃止しており、**新規に作った API キーでは 2.0 が使えない**場合があります。

このプロジェクトの**デフォルトは `gemini-2.5-flash`** に更新済みです。コードを最新のままにして再実行してください。

別モデルを試す場合は `.env` に例えば次を書きます。

```env
GEMINI_MODEL=gemini-2.5-flash
```

利用可能なモデル一覧は [Gemini モデル](https://ai.google.dev/gemini-api/docs/models/gemini) を参照してください。

### 「スクリプトの実行が無効になっているため」エラー（PowerShell）

PowerShell で `Activate.ps1` を実行できない場合、以下のいずれかを使ってください。

**方法A: バッチファイルを使う（推奨・Activate不要）**
```cmd
install.bat          ← 初回のみ：パッケージインストール
run.bat images\item1.jpg   ← ツール実行
```

**方法B: 仮想環境のPythonを直接指定**
```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe mercari_listing_generator.py images\item1.jpg
```

**方法C: PowerShellの実行ポリシーを変更**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 「GEMINI_API_KEY が設定されていません」

- `.env` ファイルがプロジェクトフォルダにあるか確認
- `.env` 内の `GEMINI_API_KEY=` の後に正しいキーが入っているか確認
- キーの前後に余分なスペースや改行がないか確認

### 「APIキーが無効です」

- [Google AI Studio](https://aistudio.google.com/apikey) でキーが有効か確認
- キーを再発行して `.env` を更新

### 画像が読み込めない

- ファイルパスが正しいか確認
- 対応形式（jpg, png, webp, gif）か確認

## 写真監視 → メルカリ出品フォーム自動入力（`photo_watcher.py`）

`images/inbox/<商品名など任意のフォルダ名>/` に写真を入れておくだけで、

1. 写真の追加が一定時間止まると自動検出
2. Geminiで商品紹介文・カテゴリー・状態・価格を生成（`data/listing_history.jsonl` にも保存）
3. ブラウザでメルカリの出品フォームを自動で開き、写真・商品名・商品説明・カテゴリー・商品の状態・価格まで自動入力

…というところまで自動化するツールです。**「出品する」ボタンは自動では押しません**。内容を確認してから、必ず自分で押してください（メルカリの利用規約・アカウントの安全のため、最終送信は人の目視確認を必須にしています）。

### セットアップ（初回のみ）

```cmd
install_auto_list.bat
```

`playwright`（ブラウザ自動操作ライブラリ）と、操作用のChromiumをインストールします。

### 使い方

```cmd
auto_list.bat
```

- 初回起動時はブラウザウィンドウが開くので、そこで**手動でメルカリにログイン**してください（ログイン情報は `playwright_profile/` にブラウザプロファイルとして保存され、次回以降は自動でログイン済みになります。パスワード自体はこのツールのコードには一切保存されません）。
- ログインが終わると `images/inbox/` の監視が始まります。
- 商品ごとにサブフォルダを作り、その中に写真を入れてください。

```
images/inbox/デニムジャケット/
  ├── front.jpg
  ├── back.jpg
  └── tag.jpg
```

- 写真の追加が止まって数秒経つと自動処理が始まり、新しいブラウザタブでメルカリの出品フォームが自動入力されます。
- 処理が終わったフォルダは `images/inbox/_done/` に、失敗したフォルダは `images/inbox/_error/` に自動で移動します。
- 終了するには、起動したウィンドウで `Ctrl+C` を押してください。

### 自動化される範囲・されない範囲

| 項目 | 自動 |
|------|------|
| 写真アップロード | ✅ |
| 商品名・商品説明文 | ✅ |
| カテゴリー | ✅（写真から推定した名称で検索し、最初の候補を選択。**必ず確認してください**） |
| 商品の状態 | ✅（生成した状態説明から6段階の選択肢に割り当て） |
| 価格 | ✅（相場調査結果から数値を抽出して入力。金額は必ず確認してください） |
| ブランド・サイズ・カラー・素材・季節感・配送方法 | ❌（任意項目のため未対応。必要なら手動で入力） |
| 「出品する」ボタン | ❌（**必ず人が最終確認して押してください**） |

カテゴリー・状態・価格は自動選択に失敗することがあります（その場合はコンソールに `⚠` 付きの警告が出ます）。出品前に必ず一通り目を通してください。

### 注意事項

- このツールは実際にログイン中のメルカリアカウントを操作します。誤った内容のまま「出品する」を押さないよう、必ず内容を確認してください。
- 自動化ツールの利用がメルカリの利用規約に抵触しないか、ご自身の責任でご確認ください。
- `playwright_profile/` にはログインセッションが保存されます。他人と共有しない・Gitにコミットしない（`.gitignore` 対象済み）でください。
- Webアプリ（`start_app.bat`）の「🚀 メルカリへ自動入力」ボタンも、同じ `playwright_profile/` を使ってブラウザを操作します。**`auto_list.bat`（写真監視）と同時には使わないでください**（同じログインセッションを取り合ってしまうため）。

## 採寸を入力して説明文に反映（Webアプリ）

Webアプリ（`start_app.bat`）で紹介文を生成すると、結果の下に **「📏 採寸を入力して説明文に反映」** という折りたたみ欄が表示されます。

1. 「種類」で **トップス（Tシャツ・シャツなど）／ズボン／スカート** を選択
   - トップス：肩幅・身幅・袖丈・着丈
   - ズボン：ウエスト・ヒップ・股上・股下・わたり幅・裾幅
   - スカート：ウエスト・ヒップ・総丈・裾幅
2. 実際に採寸した数値（cm）を入力
3. 「📐 説明文に反映」を押すと、商品紹介文の【サイズ】欄がその数値に置き換わります（未入力の項目はラベルのみ残ります）

反映した紹介文はそのままコピー・TXT保存できるほか、下の **「🚀 メルカリへ自動入力」** ボタンから、写真とあわせてメルカリの出品フォームに自動入力できます（詳細は上記「写真監視 → メルカリ出品フォーム自動入力」の「自動化される範囲・されない範囲」を参照。こちらも「出品する」は自動では押しません）。

## 固定レイアウトの紹介文

【ポイント】【カラー】【素材】【状態】【サイズ】の中身だけAIが写真から生成し、それ以外（注意書き・フォロー割・キーワード行など）は **`listing_template.py`** の固定文言で毎回同じになります。文言を変えたいときは `LISTING_BODY_TEMPLATE` を編集してください。

## 生成履歴

Web（`start_app.bat`）でも CLI（`run.bat`）でも、生成に成功すると **`data/listing_history.jsonl`** に1件ずつ追記されます（最大約500件で古いものから削除）。

- **Streamlit** 左サイドバーで過去の生成を一覧・表示・TXT保存・1件削除・全削除ができます。
- 履歴ファイルは **`.gitignore` に含まれている**ため、Git にはコミットされません（バックアップしたい場合は手元でコピーしてください）。

```

├── mercari_listing_generator.py   # メインスクリプト
├── listing_template.py            # 固定レイアウト（編集可）
├── launch_quick.bat               # ワンクリック起動（裏でStreamlit＋ブラウザ）
├── launch_quick.ps1               # 上記から呼ばれるPowerShell
├── app.py                         # Webフロント（Streamlit）
├── history_store.py               # 履歴の保存・読込
├── photo_watcher.py               # 写真監視→自動生成→出品フォーム自動入力
├── mercari_autofill.py            # メルカリ出品フォームのPlaywright自動入力
├── auto_list.bat                  # photo_watcher.py の起動バッチ
├── install_auto_list.bat          # 自動出品ツールの初回セットアップ
├── requirements.txt               # 依存パッケージ
├── .env.example                   # 環境変数テンプレート
├── .env                           # APIキー（要作成・Gitに含めない）
├── run_example.bat                # Windows用実行バッチ
├── images/                        # 画像を置くフォルダ（任意）
│   └── inbox/                     # 自動出品ツールの監視フォルダ（商品ごとにサブフォルダ）
├── playwright_profile/            # ブラウザのログインセッション（自動作成・Git対象外）
├── data/listing_history.jsonl     # 生成履歴（自動作成・Git対象外）
└── README.md                      # このファイル
```
